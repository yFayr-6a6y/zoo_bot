Telegram-бот для приютов собак
«Помощь приютам» / «AdoptBot»
Telegram-бот, предназначенный для автоматизации взаимодействия между приютами для собак, потенциальными усыновителями и волонтёрами.
Основные функции

Приветствие и первичная навигация нового пользователя
Выбор приюта (для повторных пользователей)
Информационная консультация о приюте (адрес, график, правила посещения, техника безопасности)
Полная инструкция по усыновлению животного
список доступных собак
правила знакомства
необходимые документы
подготовка дома (щенок / взрослая собака / собака с ОВЗ)
первичное общение и советы кинолога
частые причины отказа в усыновлении

Приём и валидация ежедневных отчётов усыновителей (30-дневный испытательный срок)
обязательное фото + текст
напоминания при пропуске отчёта
эскалация волонтёру после 2+ пропущенных дней
предупреждение о недостаточно подробном отчёте
завершение испытательного срока (успешно / продление / возврат)

Вызов волонтёра (встроенный чат / телефон / @username)

Этапы взаимодействия пользователя
text0 → Главное меню / выбор приюта
├── 1 → Информация о приюте
│   └── адрес, график, пропуск, правила, безопасность, контакты
├── 2 → Как взять собаку
│   └── список животных → документы → подготовка дома → советы → причины отказа
└── 3 → Ежедневный отчёт усыновителя (только после регистрации волонтёром)

Текущий статус проекта

 Структура базы данных и миграции
 Меню и состояния пользователя
 Этап 1 — информация о приюте
 Этап 2 — процесс усыновления
 Этап 3 — ежедневные отчёты + напоминания
 REST API для волонтёров
 Админ-панель волонтёра (регистрация усыновителей, завершение испытательного срока)


Бот разрабатывается для упрощения рутинной работы волонтёров приютов и повышения качества коммуникации с будущими хозяевами.
