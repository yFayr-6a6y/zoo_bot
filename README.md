# Telegram-бот помощи приютам для собак

**AdoptBot** — Telegram-бот, предназначенный для автоматизации взаимодействия между приютами для бездомных собак, потенциальными усыновителями и волонтёрами.

## Основные возможности

- Приветствие и навигация новых пользователей
- Выбор приюта для повторных обращений
- Информационная консультация о приюте (адрес, график, правила посещения, техника безопасности)
- Полное руководство по процессу усыновления:
  - список доступных животных
  - правила знакомства с собакой
  - перечень необходимых документов
  - рекомендации по подготовке дома (щенок / взрослая собака / собака с ОВЗ)
  - советы по первичному общению и контакты проверенных кинологов
  - частые причины отказа в передаче животного
- Приём и обработка ежедневных отчётов усыновителей (испытательный срок 30 дней):
  - обязательное фото + текстовое описание
  - автоматические напоминания при пропуске
  - эскалация волонтёру после 2+ пропущенных дней
  - предупреждение о недостаточно подробном отчёте
  - завершение испытательного срока (успешно / продление / возврат)
- Вызов волонтёра (встроенный перехват сообщений / телефон / @username)

## Структура взаимодействия


Бот разрабатывается для упрощения рутинной работы волонтёров приютов и повышения качества коммуникации с будущими хозяевами.
При возникновении вопросов по ТЗ — обращайтесь к основному документу со сценариями.
